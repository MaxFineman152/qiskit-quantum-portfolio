# qiskit-quantum-algorithms

A collection of quantum algorithms applied using Qiskit in Python. These are suitable for running on IBM's quantum computing cloud as of Sept 2026.

---

## Featured Projects

### Grover's Algorithm

Qiskit implementation of Grover's quantum search algorithm, demonstrating amplitude amplification to locate a marked state in an unstructured search space.

**Topics:** Quantum Computing, Grover's Algorithm, Amplitude Amplification, Qiskit

[View Project](https://github.com/MaxFineman152/qiskit-quantum-portfolio/blob/main/Qiskit%20Course/Grover's%20Algorithm.ipynb)

---

### Deutsch's Algorithm

Qiskit implementation of Deutsch's algorithm, demonstrating how quantum interference can determine whether a Boolean function is constant or balanced with a single function evaluation.

**Topics:** Quantum Computing, Deutsch's Algorithm, Quantum Interference, Qiskit

[View Project](https://github.com/MaxFineman152/qiskit-quantum-portfolio/blob/main/Qiskit%20Course/Deutsch's%20Algorithm.ipynb)

---

### Bernstein-Vazirani Algorithm

Qiskit implementation of the Bernstein-Vazirani algorithm, demonstrating how a quantum computer can determine a hidden binary string using a single oracle query.

**Topics:** Quantum Computing, Bernstein-Vazirani Algorithm, Quantum Oracles, Qiskit
